# Fantasy Racer

A pseudo-3D (OutRun-style) fantasy kart racer in the browser.
Next.js + TypeScript + Canvas 2D — no game engine.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000. Drive with **arrow keys** or **WASD**.
