# Fantasy Racer

A 3D fantasy kart racer in the browser — four realms, AI opponents, drift,
stunts, a transforming sword-mech, a championship mode, procedural sound, and
bloom lighting. Next.js + TypeScript + Three.js.

**Play:** https://fantasy-racer.vercel.app

![Fantasy Racer](docs/screenshots/void.jpg)

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

**Controls:** arrows / WASD to drive · **SPACE** nitro · **SHIFT** fly (mech) ·
brake + steer to **drift** · **C** camera · **M** sound · **Esc/P** pause ·
spin/flip mid-air for stunts.
